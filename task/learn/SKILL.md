## Execution notes

- **Scope:** Read code context, grep GLOSSARY.md for domain terms. Trivial task -> just do it, no forced options.
- **Present:** Use `AskUserQuestion` with `preview` showing code diffs. Recommended option first with "(Recommended)". Include Terms in play + Further reading. Source trust: [references.md](reference/references.md#source-trust-tiers).
- **Reinforce:** Offer Quiz/Practice/skip via `AskUserQuestion` (multiSelect). Skip when trivial, user hurried, or mastery shown. Protocols: [learn-reference.md](reference/learn-reference.md).
- **Notes:** Save to `docs/_local/learning/`. Format: [learn-reference.md](reference/learn-reference.md#learning-notes).
