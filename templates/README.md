# Templates

Base templates for project scaffolding files.
Skills read these and populate `{{placeholders}}` from user input during setup.

Projects may customize after generation - these are starting points, not schemas.

| Template | Created by | Purpose |
|----------|-----------|---------|
| CLAUDE.md | /setup Phase 1 | Project instructions with scaffold, doc map, agent coordination |
| SCOPE.md | /setup Phase 0 | In/out/uncertain table, constraints, repositories |
| _GLOSSARY.md | /setup, /grill-with-docs | Domain glossary |
| conventions-naming.md | /setup Phase 1 | Naming patterns by category (copied to `docs/program/conventions/NAMING.md`) |
| conventions-ux.md | /setup Phase 1 | Interaction patterns (copied to `docs/program/conventions/UX.md`) |
| TESTING.md | /setup Phase 1 | Test philosophy and tier expectations |
| ARCHITECTURE.md | /setup Phase 1 | Stack, key decisions, data flow summary, external dependencies |
| CONCERNS.md | Any skill (nudge) or /setup | Concern tracking with claims section |
| feature-spec.md | /setup Phase 1, /spec | Feature spec (copied to `docs/program-legacy-{source}/features/_TEMPLATE.md`) |
| logic-doc.md | /setup Phase 1 | Entity logic doc (copied to `docs/program-legacy-{source}/logic/_TEMPLATE.md`) |
